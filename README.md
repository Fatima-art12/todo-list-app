# 🧸 My To-Do List App

A cute, fully functional to-do list web app built from scratch using **HTML, CSS, and JavaScript** — no frameworks, no libraries, just the fundamentals.

🔗 **Live Demo:** [fatima-art12.github.io/todo-list-app](https://fatima-art12.github.io/todo-list-app/)

## 📖 About

This project is a mobile-style to-do list application featuring a soft, pastel "kawaii" design theme. It was built as a hands-on learning project to understand core web development concepts — from DOM manipulation to browser storage to deployment.

## ✨ Features

- ✅ **Add, complete, and delete tasks** — with a confirmation prompt before deleting
- ⭐ **Mark tasks as important** with a toggleable star
- 🔍 **Filter tasks** by All, Important, or Completed
- 💾 **Persistent storage** — tasks are saved in the browser using `localStorage`, so nothing is lost on refresh
- 📅 **Calendar view** — displays the current date
- 📊 **Stats view** — shows total, completed, pending, and important task counts
- 👤 **Profile system** — upload a profile picture and set your name, shown in the header and a dedicated profile page
- 🌙 **Dark mode** — toggle between light and dark themes, with your preference remembered
- 📱 **Mobile responsive** — adapts to full-screen view on smaller devices

## 🛠️ Built With

- **HTML5** — semantic structure
- **CSS3** — Flexbox layout, custom theming, media queries for responsiveness
- **JavaScript (Vanilla)** — DOM manipulation, event handling, `localStorage`, `FileReader` API

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```
   git clone https://github.com/Fatima-art12/todo-list-app.git
   ```
2. Open the project folder
   ```
   cd todo-list-app
   ```
3. Open `index.html` in your browser — that's it, no build tools or dependencies required!
